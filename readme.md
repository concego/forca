#  Forca Inclusiva - Eu Concego Jogar

Um jogo de forca Progressive Web App (PWA) focado em acessibilidade radical e inclusão, desenvolvido para o projeto **Eu Concego Jogar**.

Este projeto substitui o MVP original por uma versão robusta, bilíngue e visualmente completa.

## 🌍 Diferenciais Inclusivos
- **Inclusão Total:** Diferente de jogos apenas acessíveis via texto, esta versão possui uma representação visual da forca e do bonequinho, permitindo que pessoas videntes e cegas joguem juntas na mesma tela.
- **Bilinguismo:** Suporte nativo para Português e Inglês, facilitando o acesso global e a publicação em portais internacionais.
- **Acessibilidade Web:** Otimizado para leitores de tela com regiões `aria-live` e semântica correta.
- **PWA:** Instalável e funciona offline.

## 🕹️ Mecânicas
- **Categorias:** Artes, História e Ciência.
- **Chute de Palavra:** Botão "Chutar" permite tentar a palavra inteira. Acerte para vencer ou erre para o Game Over instantâneo.
